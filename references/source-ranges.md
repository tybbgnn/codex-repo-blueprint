# Source-range provenance and semantic review

Use `scripts/source_ranges.py` when generating stage 6. `block_evidence` retains operation identity, role, original span, accepted range or rejection reason; `block_ranges` and every node projection consume that single model. Keep the complete owning function source separate from selected semantic highlights.

Async-shell has disjoint block tables: `bbN` resolves only against primary inner MIR; `shell:bbN` resolves only against pinned shell MIR. Prelude nodes, attribute support, and header accounting use the shell table. Reading/execution/source-group nodes remain inner-only. Never fall back across namespaces.

- Consume statement/terminator spans, never block, body or source-scope spans as fallback highlights. Source scopes only identify enclosing context.
- Reject spans enclosing the coroutine/function body; exclude capture-parameter locations before the body. Resolve expansion call sites only when local and non-enclosing; retain a narrower nested direct span.
- Filter cleanup, implicit drop, storage lifetime and coroutine-state machinery. Unit temporaries carrying an enclosing block span are compiler bookkeeping; explicit one-line break/continue remains semantic. Explicit `drop(...)` calls are Call operations and remain eligible.
- For compiler drop flags, require a whole-body proof before omitting assignment spans: an unbound non-argument/non-return Bool local or a Bool field in the coroutine self frame reached only through proven self/Pin aliases, both literal false/true writes, no debug binding (including aliases), captured-pointee access or escape, and every read a SwitchInt whose Drop arm rejoins its bypass without additional effects. Missing metadata or any other use keeps the span. This filter changes highlights only; BB facts, membership and business Boolean writes remain intact. The helper is compiler_drop_flags(raw), with positive and business-state negative tests.
- Decisions use business SwitchInt records from `sourceInventory`, including an outcome's owning action guards; preserve original execution/path evidence separately. Use precise Call conditions only when no SwitchInt exists. A complete operation span is an upper bound. Union the exact local Discriminant assignment feeding a SwitchInt when its terminator locates only the pattern; ignore unrelated statements. Complete only unfinished anchored calls/RHS and their await, stopping before a new short-circuit operand, a later method call or the body. This lexical completion is not a Rust parser; unusual raw-string/macro grammar requires agent evidence review.
- Merge only overlapping or adjacent intervals. The 25% contract uses the inclusive union, not the bounding envelope. Record a concrete `broadRangeReason` for a justified goal/action/execution exception. Phase ranges are exempt. No precise semantic source means empty ranges plus `sourceRangeReason`, not an invented entry line or retained function body.

Audit every requested goal/action/execution and a stated BB-group sample by reading the highlighted source, not by name similarity or line overlap. Record correct/partial/wrong, actual code behavior, mapping vs membership vs title cause, and the concrete remedy. Keep unresolved case-specific membership boundaries explicit; do not move BBs solely to improve range size. Machine passes do not close these semantic findings.

BB groups require independent local-path descriptions, not copied parent-action responsibilities. Stage-2 generators should apply source-reviewed per-group descriptions with exact BB evidence equality; reject stale descriptions when the membership changes. Re-read the actual highlights after applying those descriptions. Technical-only groups name their compiler role and record absence of a source highlight. A sample certifies only the sampled descriptions, not the remaining groups.

Single-line unit temporaries on the owning function signature/opening brace have no semantic source span; explicit unit expressions inside the body remain eligible. Source-less and empty-detail exceptions use the shared classification registry described in SKILL.md; no separate per-rule exception is defined here.

Run `verify_source_evidence.py` as well as `check_source`. The former imports no range-generation or classification code and checks raw decision bounds, header bookkeeping, event-macro claims, async-shell binding/prelude exactness, attribute ownership, and narrow span-wrapper claims independently. Attribute support for an async-shell prelude comes only from its pinned shell raw; inner nodes cannot claim attribute lines. The latter regenerates projections to check provenance/determinism, so it cannot catch a shared generator bug.
